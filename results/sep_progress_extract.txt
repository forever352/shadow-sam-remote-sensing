地理与信息工程学院2025-2026 学年
大学生创新创业训练计划项目
5 月进度表
项目名称 基于方向提示与 SAM 的遥感影像阴影检测方法研究
汇报月份 2026 年 5 月
本月各成员工作进展介绍：
潘俊豪（负责人）：
1.系统架构设计与算法整合：主导设计并实现了全自动阴影检测流水线
（shadow_pipeline.py）。成功将前期的物理特征流与 SAM 模型精细分割流进行
闭环整合，实现“输入原图→自动提取→自动布点→SAM 精分”的端到端自动
化。
2.核心算法攻坚（距离变换）：针对阴影不规则形状导致的布点偏离问题，放弃
了传统的几何质心算法，创新性地引入了“距离变换（Distance Transform）”算
法。通过计算连通域内离边界最远的点作为高置信度提示点，保证了 Prompt（提
示点）100%落在阴影内部。
3.团队统筹与中期答辩准备：组织召开 5 月进度研讨会，分配算法调参与数据测
试任务。牵头撰写中期答辩报告，制作汇报 PPT，将团队近三个月的“算法迭代
历程（从手动点击到全自动，从全局阈值到自适应硬约束）”整理为系统性的学
术成果。
吴箫：
1.算法实验参与：紧密配合团队的整体研究进度，参与了基于“方向提示与 SAM”
阴影检测流水线的集成测试工作，并在标准遥感数据集上协助运行了多组对比实
验。
后处理优化协助：协助小组进行后处理环节的策略微调，参与测试了利用面积和
长宽比过滤剔除路面噪声的实际效果，并协助整理了实验数据与效果对比图表。
技术文献调研：围绕项目中期答辩的需求，协助团队梳理了关于遥感垂直领域大
模型适配的相关参考文献，为项目报告的完善提供了辅助材料。
2.遇到的困难及解决办法困难：在参与高密度建筑群场景的泛化性测试时，发现

算法在面对建筑物互相遮挡时，偶尔会出现碎屑状阴影边界粘连的问题。
解决办法：及时将测试结果和数据反馈给组内负责核心代码的同学，并配合小组
共同调研了通过微调大模型解码器（Mask Decoder）引入交叉注意力机制的潜在
方案，目前该问题正在逐步优化中。
3.个人主要收获与体会技能提升：通过本月深度参与小组的实验与讨论，对遥感
影像中的“异物同谱”难题以及自适应动态阈值的设置原理有了更深入的理解。
团队协作：进一步熟悉了基于 GitHub 的代码版本。
陈波丞:
1.算法实验与实现：
紧密配合团队整体研究进度，独立完成了 C3I 粗糙提取算法的实现与小实验验
证，为后续阴影检测流程提供了关键的预处理模块支撑。在标准遥感数据集上完
成了算法的基础测试，验证了其对阴影区域的初步提取效果，并与现有方法进行
了初步对比。技术调研与答辩准备：围绕项目中期答辩的需求，梳理了 C3I算法
的技术原理与实现细节，整理了相关实验数据与流程，为项目报告和答辩材料的
准备提供了支持。同时，系统学习并熟悉了 GitHub 代码仓库的上传操作、版本
管理流程及其在团队协作中的作用，为后续代码协同与成果管理做好了准备。
2.遇到的困难及解决办法：
困难：在实现 C3I粗糙提取算法的过程中，遇到了部分场景下阴影提取边界粗糙、
与非阴影区域粘连的问题，影响了后续处理的精度。
解决办法：通过查阅相关文献，调整了算法中关键阈值参数，并结合团队讨论优
化了预处理流程，有效改善了边界粘连现象，目前算法提取效果已能满足后续模
块的基本需求。
3.个人主要收获与体会：
技能提升：通过独立实现 C3I算法，加深了对遥感影像阴影提取流程的理解，锻
炼了算法实现、调试与优化的能力。
团队协作与工具掌握：熟悉了 GitHub 的代码上传与版本管理操作，提升了项目
协作与成果管理的意识，为后续团队开发打下了良好基础。
周杭：
本月主要完成了两方面工作：
--- page 3 ---
1.熟悉了 GitHub 的基本操作，包括代码克隆、提交、分支管理及远程协作流程，
建立了项目私有仓库并整理了现有脚本，为后续代码开源打下基础。
2.针对阴影检测中“阴影未完全被染色”的问题进行了代码修改。分析发现，原
方法中方向提示稀疏且 SAM 后处理阈值固定，导致部分阴影区域内部空洞、边
缘不完整。为此，从三个方面修改代码：增强方向提示的采样密度、增加形态学
后处理以修复掩膜连通性、将固定阈值改为自适应阈值。修改后，阴影掩膜的完
整度显著提升，未染色区域的像素占比由约 15%降至 3%左右，视觉效果更加连
续。
3.开展了团队协作工作，与课题组同学完成了代码仓库的分支协同调试，通过 pull
request 合并了两次针对方向提示生成的改进。
